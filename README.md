# BusinessSuite - Commercial ERP & Multi-Tenant SaaS Platform

نظام تجاري متكامل لإدارة المبيعات والمشتريات والمخزون والعملاء والمدفوعات التشغيلية، يدعم العمل كمنصة سحابية متعددة الشركات (Multi-Tenant SaaS) بنظام باقات واستحقاقات ديناميكية أو كنظام مستقل لعميل واحد (Single-Tenant On-Premise).

---

## 1. المميزات المعمارية والوظيفية الأساسية

- **بنية متينة Modular Monolith**: خادم NestJS كمرجع وحيد لمنطق الأعمال والحسابات المالية والتفويض، مع واجهة Next.js 14+ باللغتين العربية (RTL افتراضيًا) والإنجليزية.
- **عزل صارم للشركات (Multi-Tenancy)**: عزل على مستوى قاعدة البيانات PostgreSQL باستخدام مفاتيح مركبة وسياسات Row-Level Security (RLS)، مع اشتقاق سياق الشركة من الجلسة الموثقة دون الوثوق بمدخلات المتصفح.
- **نظام باقات واستحقاقات ديناميكي بالكامل (Dynamic Entitlements)**:
  - تعديل الباقات، المزايا، والحدود من لوحة مالك المنصة ينعكس فورًا على واجهات وطلبات الـ API للشركات دون تعديل كود أو إعادة تشغيل أو نشر.
  - دعم استثناءات مخصصة لكل شركة (Allow / Deny Features & Quota Overrides).
- **المبيعات والمشتريات والمرتجعات**:
  - دورة المستند: Draft $\rightarrow$ Posted.
  - ترحيل الفاتورة هو الحدث الحصري لخصم أو إضافة المخزون ومنع الازدواجية.
  - حساب دقيق للمرتجعات مع منع تجاوز الكميات القابلة للإرجاع.
- **المخزون وحساب التكلفة**:
  - احتساب تكلفة البضاعة بطريقة المتوسط المرجح المتحرك (Moving WAC).
  - تجميد التكلفة (COGS Snapshot) وقت البيع للحفاظ على دقة الأرباح التاريخية.
  - منع المخزون السالب بشكل ذري داخل المعاملات.
- **الخزائن والتحصيل وسندات القبض والصرف**:
  - إدارة الخزائن النقدية والحسابات البنكية وسندات القبض والصرف وتوزيع الدفعة الواحدة على فواتير متعددة.
- **التقارير وحماية التكلفة**:
  - تقارير مبيعات، مشتريات، تقييم مخزون، مديونيات، ومجمل ربح تشغيلي مع حجب التكلفة للأدوار غير المصرح لها.

## 3. التشغيل المحلي السريع (Local Development)

### 3.1 تثبيت الحزم وإعداد البيئة
```bash
# 1. تثبيت كافة الاعتماديات في الـ Monorepo
npm install

# 2. إنشاء ملف الإعدادات
cp .env.example .env
# تأكد من ضبط DATABASE_URL في ملف .env
```

### 3.2 تهيئة قاعدة البيانات وبذر البيانات الأولية
```bash
# 1. بناء الحزمة المشتركة
npm run build --workspace=@business-suite/shared

# 2. مزامنة قاعدة بيانات PostgreSQL
npx prisma db push --schema=apps/api/prisma/schema.prisma

# 3. بذر الباقات وحساب مالك المنصة وشركات العرض
npx ts-node apps/api/prisma/seed.ts
```

### 3.3 تشغيل الخادم والواجهة
```bash
# تشغيل خادم NestJS API (على المنفذ 4000)
npm run start:dev --workspace=@business-suite/api

# تشغيل واجهة Next.js (على المنفذ 3000)
npm run dev --workspace=@business-suite/web
```
